# Pokemon Purple DX

Polished Flipper-native demo focused on visuals and feel.

## Features
- Better title screen
- Proper starter selection
- Cleaner 1-bit overworld
- Player sprite, grass, trees, houses
- Random encounters
- Cleaner battle scene
- HP bars
- Stylized monster sprites
- Hold Back to exit from anywhere

## Controls
- D-pad: move/select
- OK: select / attack
- Back: go back / run
- Hold Back: exit app
